Мой учебный репозиторий для курса по DevOps.
Здесь я буду сохранять скрипты, конфигурации и домашние задания.

## О файлах .gitignore
- **Корневой `.gitignore`**: игнорирует логи (`*.log`), секреты (`.env`), системные метаданные (`.DS_Store`, `Thumbs.db`) и кэш языков (`__pycache__/`).
- **`terraform/.gitignore`**: игнорирует локальные файлы состояния (`*.tfstate`, `*.tfstate.*`), кэш плагинов, временные файлы и резервные копии. Это гарантирует, что в репозиторий попадает только код инфраструктуры, а не локальные данные и секреты.

## Описание правил в terraform/.gitignore

В файле `terraform/.gitignore` используются следующие паттерны игнорирования:

| Паттерн | Что игнорирует |
|---------|---------------|
| `.terraform/` | Любую директорию с именем `.terraform/` и всё её содержимое |
| `*.tfstate` | Все файлы, имя которых заканчивается на `.tfstate` |
| `*.tfstate.*` | Все файлы, начинающиеся с `.tfstate.` и имеющие любое продолжение (например, `.tfstate.backup`) |
| `crash.log` | Файл с точным именем `crash.log` |
| `crash.*.log` | Файлы, где между `crash.` и `.log` есть любой символ или набор символов (например, `crash.1.log`) |
| `*.tfvars` | Все файлы, заканчивающиеся на `.tfvars` |
| `*.tfvars.json` | Все файлы, заканчивающиеся на `.tfvars.json` |
| `override.tf` | Файл с точным именем `override.tf` |
| `*_override.tf` | Все файлы, заканчивающиеся на `_override.tf` (звёздочка — любой префикс) |
| `!example_override.tf` | **Исключение**: файл, который НЕ нужно игнорировать, даже если он попадает под другой паттерн (знак `!` отменяет игнорирование) |
| `.terraformrc` | Файл с точным именем `.terraformrc` |
| `*.dot` | Все файлы с расширением `.dot` |

### Общие правила синтаксиса, использованные в файле:
- `*` (звёздочка) — заменяет **любую последовательность символов** (включая пустую)
- `?` (вопросительный знак) — заменяет **один любой символ**
- `/` в конце — указывает, что паттерн применяется только к **директориям**
- `!` в начале — **отменяет** игнорирование для подходящих файлов (негативный паттерн)
- Паттерны без `/` в начале применяются ко **всем уровням вложенности**
- Комментарии начинаются с `#` и игнорируются самим gitignore
